# Lessons (phase 3) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A learner opens the next lesson of their bundle, discovers 10 words, does about 12 exercises, and the words join reading reviews; every 3 lessons a writing session adds writing reviews. Progress syncs.

**Architecture:** `core/curriculum` (pure) decides lesson order, exercises, scores and seeded scheduling state. `useContent` loads `public/content/<bundle>/` JSON on demand. Finishing a lesson writes, in one transaction, a `lessonProgress` row, the words as cards in a per-level curriculum deck with deterministic ids, their items and the lesson's attempts. Pages: `/lessons`, `/lessons/[id]`, a next-step card on Today, a level step in onboarding.

**Tech Stack:** Nuxt 4 SPA, Vue 3, Dexie 4, Kanto, Supabase, Vitest + fake-indexeddb, Playwright.

**Spec:** `docs/superpowers/specs/2026-11-21-mainland-taiwan-curriculum-design.md` (phase 3 of 3)

## Global Constraints

- `core/curriculum`, `core/srs`, `core/chinese` pure. Pages reach data only through composables. Kanto first (native elements need an allowlist entry). Copy English, sentence case. Kanto tokens only. Commits authored by Arnaud Michel alone, no AI trailer.
- Content shape: `core/curriculum/types.ts` (`Word`, `Reading`, `Example`, `LessonRef`, `UnitRef`, `LevelRef`, `ContentIndex`). Files: `public/content/<bundle>/index.json`, `level-<n>.json` (a `Word[]`).
- Ids: card id = word id (`hsk1-0042`); deck id = `curriculum:<prefix><level>` (`curriculum:hsk1`, `curriculum:tbcl3`); item ids from the existing `itemId(cardId, dir)`. Deck name = the level's `name` (`HSK 1`, `HSK 7–9`, `Taiwan 3`), tag `HSK` or `TBCL`, colour token `var(--chart-series-1)`, bundle = the content's bundle.
- Reading item = direction `recognition`; writing item = direction `production`.
- Seeded state after a lesson or writing session: the active scheduler applied to `newSrsState(now)` with grade 3 for a word answered right every time in that lesson, grade 1 otherwise; a right word's `due` is at least the next local day at 04:00. These items skip `newPerDay`.
- Lesson answers are attempts with `source: 'lesson'`, mode `writing` for the writing exercise and `review` for every other kind, grade 3 if right, 1 if wrong. Buffered; written only when the lesson finishes. An abandoned lesson writes nothing.
- Statistics count `lesson` attempts with practice (`core/stats/activity.ts` splits `practice` vs the rest: `lesson` goes with `practice`).
- Daily goal: `Settings.dailyLessons`; a writing session counts as a lesson.
- Next step: the first lesson not done in level order, or a unit's writing session once its 3 lessons are done; every lesson stays open.

## Review Focus

- A lesson whose words include one with no example → the cloze and order exercises skip that word; the lesson still has ≥ 10 exercises when the lesson has 10 words. Test in Task 1.
- Finishing the same lesson twice (re-doing it) → no duplicate cards or items; the progress row is updated, items keep their history. Test in Task 4.
- A word in a lesson that is already a card in the learner's own deck (same hanzi, different id) → both exist; nothing is merged. Test in Task 4.
- The content file fails to load (offline web, missing file) → `/lessons` shows a retry state, not a blank page. Test in Task 2.
- Switching bundle on `/lessons` → the list reloads for the new bundle. e2e in Task 8.

### Task 1: The lesson engine

**Files:**
- Create: `core/curriculum/engine.ts`, `core/curriculum/exercises.ts`, `core/curriculum/schedule.ts`
- Test: `test/curriculum/engine.test.ts`, `test/curriculum/exercises.test.ts`, `test/curriculum/schedule.test.ts`

**Interfaces:**
- `type Step = { kind: 'lesson'; lesson: LessonRef; level: LevelRef } | { kind: 'writing'; unit: UnitRef; level: LevelRef }`
- `writingId(unitId: string): string` → `${unitId}-writing`
- `nextStep(index: ContentIndex, done: ReadonlySet<string>): Step | null`
- `type Exercise = { kind: 'meaning-to-hanzi' | 'hanzi-to-meaning' | 'reading' | 'listening' | 'cloze' | 'order' | 'writing'; wordId: string; prompt: string; choices?: string[]; answer: string | string[] }`
- `buildExercises(lesson: Word[], level: Word[], rng: () => number, opts: { listening: boolean; writing: boolean }): Exercise[]` — 12 for a 10-word lesson (count = `max(lesson.length, min(12, lesson.length + 2))`), every word at least once, 4 choices with distractors from the lesson then the level (no duplicates, never the answer twice), reading choices = the word's syllables with other tones on the first syllable whose tone differs, cloze/order only for words with an example, at most one writing exercise, kinds spread so no kind appears three times in a row.
- `seededRng(seed: string): () => number` (deterministic, e.g. mulberry32 over a string hash).
- `scoreLesson(results: { wordId: string; right: boolean }[]): { right: number; total: number; missed: string[] }`
- `seedState(scheduler: Scheduler, settings: SchedulerSettings, right: boolean, now: number): SrsState` (the rule in Global Constraints).
- `writingCharacters(words: Word[], hasStrokes: (ch: string) => boolean): { wordId: string; chars: string[] }[]` — Han characters with stroke data, word order; words with none are left out.

### Task 4: Finishing a lesson or a writing session

**Files:**
- Create: `core/db/curriculum.ts`, `app/composables/useLesson.ts`
- Test: `test/db/curriculum.test.ts`

**Interfaces:**
- `completeLesson(input: { bundle: Bundle; level: LevelRef; lesson: LessonRef; words: Word[]; results: LessonResult[]; durationMs: number; now: number; scheduler: Scheduler; settings: SchedulerSettings }): Promise<void>` where `LessonResult = { wordId: string; exercise: Exercise['kind']; right: boolean; at: number; durationMs: number }`. In one transaction: ensure the level deck; for each word create the card if missing (hanzi; pinyin from the first reading via `parsePinyin`; zhuyin from the first reading or `toZhuyin`; translation = the first reading's meanings joined `; `; other readings appended to `note` as `pinyin: meanings` lines; example fields from `example`; tags `[level name]`) and the `recognition` item if missing, seeded with `seedState` (right = every result for that word right); log each result as an attempt (`source: 'lesson'`); put the progress row (`kind: 'lesson'`, `known: false`). Re-doing a lesson creates nothing new and keeps existing items.
- `completeWriting(input: { bundle; level; unit: UnitRef; words: Word[]; results: { wordId; right; at; durationMs }[]; now; scheduler; settings })` — adds the `production` item (seeded the same way) to each word that has a card and stroke data; progress row `kind: 'writing'`.
- `useLesson(id: string)` — resolves the lesson or writing session from the index, loads its words, builds exercises with `seededRng(id + startedAt)`, collects results, `finish()` calls the above with the active scheduler and settings, then refreshes due counts.

- [ ] Implement, run, commit — `Turn a finished lesson into cards, reviews and progress`
